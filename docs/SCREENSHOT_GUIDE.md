# Screenshots and demo video: shot list

Screenshots must be taken from your running app (`streamlit run app.py`). Save them in `docs/screenshots/` with these exact names; the README already links to them.

| File name | Page | What to capture |
|---|---|---|
| `01_overview.png` | Executive Overview | Full page, top section |
| `02_rise_and_fall.png` | Rise & Fall | The main trend chart |
| `03_captains_coaches.png` | Captains & Coaches | Win % bars with the tab visible |
| `04_captain_coach_impact.png` | Captain & Coach Impact | Pair grid + rolling win % |
| `05_match_predictor.png` | Match Predictor | What-if scenario + model comparison table |
| `06_ask_the_data.png` | Ask the Data | One question with the answer and the "How this was computed" box open |
| `07_match_one_pager.png` | Match One-Pager | Run-rate worm and scorecard |
| `08_data_quality.png` | Data Quality | The page that shows coverage and limits |

Tips: browser zoom 80 to 90%, window about 1400 px wide, hide the Streamlit "Deploy" bar (menu, Settings, Developer mode off), do not show your API key.

## 60-second demo video (suggested order)
1. 0:00 Executive Overview (5 s), say the one-line pitch.
2. 0:05 Rise & Fall or Tournaments (10 s).
3. 0:15 Captains & Coaches, switch format (10 s).
4. 0:25 Match Predictor, change opponent and show the probability move (12 s).
5. 0:37 Ask the Data: click an example question, open "How this was computed" (15 s).
6. 0:52 Data Quality, point at the confidence notes (8 s).

Record with Windows Game Bar (Win + G) or OBS, export as MP4 or GIF, and put it at `docs/demo.mp4` (or link a YouTube/Loom URL in the README).
